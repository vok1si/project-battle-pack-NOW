# Project Battle Pack — NOW

Restored distribution repository for the Project Battle Minecraft mod pack.

The launcher manifest is committed to the repository. Mod JAR files and the
matching recovery assets are attached to GitHub Release `v0.1.0` so the
launcher can download them using stable release URLs.

## Manifest

`launcher-manifest.project-battle.generated.json`

The manifest contains SHA-256 hashes and sizes for every managed mod file.


## Code signing policy

Current status: the application for SignPath Foundation code signing has not yet been approved. No Project Battle Launcher release is currently signed with a SignPath Foundation certificate.

Read the [Project Battle Code signing policy](https://project-battle-portal.vokisu9.workers.dev/code-signing-policy.html) for the source, build, release approval, team, and privacy details. The MIT license in the separate launcher source repository applies only to the files in that repository; this distribution repository and its game/modpack contents are not covered by that license.
